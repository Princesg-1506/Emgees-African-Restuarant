# Emgees African Restaurant & Bakery Clone

This project is a frontend clone website built for self-enhancement and practice in frontend development. It is inspired by the Emgees African Restaurant & Bakery brand and is intended as a learning-focused recreation of a restaurant landing page, not an official production website.

## Project Overview

Emgees African Restaurant & Bakery is presented as a modern African restaurant landing page with a warm, premium visual style. The site includes:

- A full-screen hero section with restaurant branding and a background video
- Promotional call-to-action buttons for ordering and menu browsing
- Signature dish cards for Nigerian and West African cuisine
- About and specialty content sections
- FAQ blocks for customer information
- Contact details and a location map section
- Responsive styling for desktop and smaller screens

This project is a clone website created to strengthen skills in HTML structure, CSS styling, layout design, visual hierarchy, and responsive frontend implementation.

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- Font Awesome icons
- Embedded Google Maps iframe
- Local asset files for branding, food images, and video content

## Project Structure

- `index.html` — main page structure and content
- `stylesheet.css` — all styling for layout, colors, typography, and responsiveness
- `assets/` — logo, food images, and video/media assets

## How to Run

Because this is a static web page, you can run it by opening `index.html` directly in a browser.

For a better local development experience, you can also serve it with a lightweight local server such as:

- VS Code Live Server
- Python HTTP server
- Any static file server of your choice

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
